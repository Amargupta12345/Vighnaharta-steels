# Admin Demo Data

Use this document to fill the admin panel quickly for a demo.

Recommended order:

1. Add categories first: `/admin/categories`
2. Add brands second: `/admin/brands`
3. Add products last: `/admin/products/add`

Keep `Active` checked for categories and brands. Keep `In stock` checked for products unless you want to demo an unavailable item. Slugs auto-fill from the name, but the exact slugs are included below.
